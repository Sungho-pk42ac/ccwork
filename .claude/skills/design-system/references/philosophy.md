# Creative North Star: The Curated Archive

이 디자인 시스템은 고급 디지털 아틀리에의 철학을 따른다. Notion의 유틸리티에서 영감을 받되, **Soft Minimalism** 영역으로 실행을 확장한다. 모든 노트를 개인 박물관의 소장품처럼 다룬다.

## 핵심 원칙

| 원칙                      | 설명                                                      |
| ------------------------- | --------------------------------------------------------- |
| **Soft Minimalism**       | 부드럽고 절제된 미니멀리즘. UI가 콘텐츠와 경쟁하지 않는다 |
| **Intentional Asymmetry** | 의도적 비대칭으로 "generic SaaS" 느낌을 탈피              |
| **Tonal Depth**           | 단단한 경계선 대신 배경색 톤 차이로 깊이를 표현           |

## 설계 철학

콘텐츠를 딱딱한 테두리 컨테이너에 가두지 않는다. 대신 정교한 뉴트럴 톤 레이어 위에 콘텐츠를 띄워, 타이포그래피가 숨 쉬고 정보가 주인공이 되도록 한다. 학습의 "고요한 순간"을 우선하며, UI는 절대 인사이트와 경쟁하지 않는다.
