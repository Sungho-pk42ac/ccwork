# 태그 기능 정의서 (확정)

## 기능 개요

노트에 태그를 추가하고 관리할 수 있다.

## 데이터 구조

- `Note` 타입에 `tags: string[]` 필드 추가
- 기존 노트(tags 필드 없음)는 `tags ?? []`로 빈 배열 폴백 처리
- db.json의 기존 노트 데이터에도 `tags: []` 추가

## 태그 입력 UI

- **위치**: NoteEditor 내 내용(textarea) 아래, 버튼 영역 위
- **입력 방식**: 텍스트 입력 + Enter 또는 쉼표(`,`)로 태그 추가
- **표시 방식**: 추가된 태그는 칩(badge) 형태로 나열, 각 칩에 X 버튼으로 개별 삭제
- **표시 순서**: 입력 순서 유지

## 유효성 검증

- 빈 문자열 불허
- 앞뒤 공백 자동 trim
- 대소문자 구분 없이 중복 체크 (`React`와 `react`는 동일 태그)
- 저장 시 소문자로 정규화
- 글자 수/개수 제한 없음

## 저장 방식

- 태그는 노트 저장 시 title, content와 함께 저장 (기존 저장 플로우 유지)
- 태그만 별도 즉시 저장하지 않음
- API 호출 시 `tags` 배열을 함께 전송

## NoteList 표시

- NoteItem에 태그 칩을 간략히 표시 (읽기 전용)
- 태그가 없으면 태그 영역 미표시

## 범위 외 (향후 고려)

- 태그별 필터링/검색
- 태그 자동완성
- 태그 색상/카테고리
- 태그 개수/글자 수 제한
